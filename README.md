# K-Means Lab

An interactive, step-by-step K-Means lab for CIS 460 Machine Learning at Cleveland State University. Every assignment and center update can be examined one calculation at a time.

## Using the lab

Open the published page, or open `index.html` in a browser. There is nothing to install.

- **Next step** and **Previous** move through the algorithm one operation at a time. **Play** runs it automatically.
- **Data** selects the 10-student exam scores, the students' hours and scores, the two moons data, or random groups.
- **Starting centers** selects a well-spread start, a poor start, random points or k-means++. With k-means++, each draw can be stepped through and shows every point's chance of selection.
- **Standardize features** compares raw and scaled distances.
- Select any point to see its distance calculations.
- **Completed runs** records each finished run, so results can be compared.
- **Guided experiments** load prepared setups with questions.
- **K-Means vs DBSCAN** runs both methods side by side, with live sliders for `eps` and `min_samples`.

## Files

| File | Purpose |
|---|---|
| `index.html`, `styles.css` | Page and layout |
| `app.js` | Lab controls and drawing |
| `compare.js` | K-Means vs DBSCAN section |
| `quiz.js` | Student knowledge check |
| `kmeans.js` | K-Means and DBSCAN calculations, with no page code |
| `moons.js` | `make_moons(200, noise=0.05, random_state=0)`, generated by `tests/make_reference.py` |
| `blobs.js` | `make_blobs(200, centers=3, cluster_std=1.0, random_state=4)`, generated by the same script |
| `tests/verify.js` | Compares `kmeans.js` with scikit-learn and the course figures |

To run the checks (requires Node.js):

```bash
node tests/verify.js
```

To regenerate the reference values (requires scikit-learn):

```bash
python tests/make_reference.py
```

## Publishing with GitHub Pages

In the repository, open **Settings > Pages**, set the source to **Deploy from a branch**, and choose `main` and `/ (root)`.
