The method

K-Means is an unsupervised method: it receives no correct answers and groups points by distance alone. The example below uses the exam scores from class with K = 3 and starting centers 30, 61 and 92.

  1. Choose K

    K is the number of clusters. The analyst sets it before the algorithm runs; K-Means does not determine it.

  2. Place K starting centers

    A center is a location. It begins at a data point in this lab, and after the first update it is usually not one. k-means++, the scikit-learn default, chooses starting points that tend to lie far apart.

  3. Assign each point to the nearest center

    Compute the distance from the point to every center and keep the smallest.

    d(p, c) = √[ (xp − xc)² + (yp − yc)² ]

    Example. Student A scored 58. The distances to 30, 61 and 92 are 28, 3 and 34, so A joins the center at 61.

  4. Move each center to the mean of its points

    Average each feature separately over the points in the cluster.

    cj = (1 / nj) Σi in cluster j xi

    Example. Students B, D, G and J scored 30, 32, 42 and 45. Their mean is 149 / 4 = 37.25, so that center moves to 37.25.

  5. Repeat until no point changes cluster

    Once memberships stop changing, the centers stop moving as well. In this example the final centers are 37.25, 59.33 and 89.33.

What K-Means minimizes

The objective is inertia, also called the within-cluster sum of squares or SSE: the squared distance from each point to its own center, added over all points. Lower inertia means tighter clusters.

inertia = Σj Σi in cluster j ‖xi − cj‖²

Assignment cannot raise inertia, because each point moves only to a center at least as close. Update cannot raise it either, because the mean is the location with the smallest total squared distance to the cluster's points. There are finitely many possible groupings, so the algorithm must stop. It may stop at a local minimum rather than the best possible grouping, which is why the start matters.

The same run in scikit-learn

from sklearn.cluster import KMeans
import numpy as np

scores = np.array([58, 30, 59, 32, 61, 86, 42, 90, 92, 45]).reshape(-1, 1)
start = np.array([[30], [61], [92]])

model = KMeans(n_clusters=3, init=start, n_init=1).fit(scores)
print(model.cluster_centers_.ravel())   # final centers
print(model.labels_)                    # cluster of each student
print(model.inertia_)                   # inertia

By default, scikit-learn uses k-means++ and keeps the best of its runs. The fixed init above reproduces a single run from this lab.

Reading the figure. The best achievable inertia keeps falling as K grows, so the smallest inertia cannot select K. Look instead for the elbow, where additional clusters stop producing large reductions. The silhouette score compares how close each point is to its own cluster and to the nearest other cluster; values nearer 1 are better.

Remark. These are guides only. The elbow can be ambiguous, and the most useful K also depends on what the clusters will be used for.

When K-Means fits

Suitable when

  • Features are numeric and on comparable scales
  • Clusters are compact and roughly round
  • Every observation should belong to a cluster
  • A fast method for large data is needed

Use caution when

  • Outliers can pull a mean away from its group
  • Clusters are curved, nested or very unequal in size
  • Noise points should stay unassigned; DBSCAN allows this
  • The number of clusters is unknown and hard to judge
